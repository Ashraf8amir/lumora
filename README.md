## Overview

Lumora is a modern backend application built with NestJS following enterprise architecture principles.

The project focuses on scalability, maintainability, clean architecture, and production-ready development practices.

---

## Features

- JWT Authentication
- Refresh Token Authentication
- Role-Based Access Control (RBAC)
- Email Verification
- Password Reset
- User Management
- MongoDB Integration
- Redis Caching
- Swagger API Documentation
- Global Exception Handling
- Request Validation
- Structured Logging
- Docker Support
- CI/CD Ready

## Getting Started

### Install dependencies

```bash
npm install
```

### Configure environment

```bash
cp .env.example .env
```

### Start development server

```bash
npm run start:dev
```
